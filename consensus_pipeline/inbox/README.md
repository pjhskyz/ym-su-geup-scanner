# 컨센서스 원자료 넣는 곳

날짜가 들어간 CSV를 이 폴더에 넣으면 `build_consensus_data.py`가 읽어 `history/`에 날짜별로 보관하고 `consensus_data.json`을 만듭니다.

- **FnGuide 스크리너 엑셀은 내려받은 그대로 넣으면 됩니다.** 파일명에 들어 있는 날짜(`…_20261123115316.xlsx`)를 관측일로 쓰고, `영업이익(FY1)(억원)`·`영업이익(FY2)(억원)` 열을 읽습니다. `Fwd.12M` 열은 머리글과 값의 단위가 달라 읽지 않습니다.
- FY1은 "올해 추정"이라 결산이 반영돼 기준 연도가 넘어가는 시점에는 값이 크게 바뀝니다. 그 전후 비교는 추정치 변경이 아니니 걸러서 보세요.
- CSV 파일명: `YYYY-MM-DD.csv` 또는 `YYYYMMDD_아무이름.csv` (파일명의 날짜가 관측일)
- 인코딩: UTF-8 또는 CP949
- 필수 열: `종목코드`(또는 `code`), `영업이익`(또는 `op`, 억원)
- 선택 열: `종목명`(`name`), `대상분기`(`period`, 예: `2026.12` 또는 `202612`)
- 값이 없는 칸은 비워 둡니다. 0으로 채우지 마세요.

이용 계약이 있는 자료만 넣으세요. 이 저장소가 공개 저장소라면 원자료 CSV는 커밋하지 말고 `history/`의 가공본만 올리는지 제공처 약관을 확인하세요.
